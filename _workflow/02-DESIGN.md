## ۲. رنگ‌ها

> اگر هگز ندارید، فقط اسم رنگ‌ها را بنویسید (مثلاً «نقره‌ای سرد + سفید + کمی کرم»)
> و من پالت را پیشنهاد می‌دهم.

| نقش | متغیر | هگز | توضیح |
|---|---|---|---|
| زمینهٔ اصلی | `--bg-base` | | رنگ غالب صفحه |
| سطح روشن | `--bg-white` | | کارت‌ها، سطوح محتوا |
| زمینهٔ فرعی | `--bg-cream` | | فقط ۱ تا ۲ بخش، برای گرما |
| متن اصلی | `--ink-strong` | | هرگز مشکی خالص |
| متن فرعی | `--ink-muted` | | کپشن و توضیحات |
| اکسنت | `--accent` | | آیکون، هایلایت، حالت فعال |
| اکسنت تیره | `--accent-deep` | | هاور و تأکید |
| خط و بوردر | `--accent-line` | | هرلاین یک‌پیکسلی |
| سایه | `--shadow` | | خیلی نرم و کم‌شفافیت |
| موفقیت | `--success` | | فقط معنایی |
| خطا | `--danger` | | فقط معنایی |

**قوانین استفاده** (اگر نظر خاصی دارید بنویسید، وگرنه پیش‌فرض من همین است):

- زمینهٔ صفحه `--bg-base`؛ بخش‌ها بین `--bg-base` و `--bg-white` یکی‌درمیان.
- `--bg-cream` حداکثر در ۱–۲ بخش، هرگز به‌عنوان رنگ غالب.
- دکمهٔ اصلی: زمینه `--ink-strong`، متن `--bg-white`، هاور `--accent-deep`.
- دکمهٔ فرعی: بدون زمینه، بوردر ۱px `--accent-line`، هاور زمینه `--bg-white`.
- فقط یک رنگ اکسنت. دو فلز/دو اکسنت هم‌زمان = کیچ.

## ۷. چک‌لیست تحویل

بعد از اجرا این‌ها را بررسی می‌کنم و گزارش می‌دهم:

- [ ] هیچ رنگی خارج از توکن‌ها در کد نمانده باشد
- [ ] کنتراست متن روی هر سه زمینه قابل خواندن باشد
- [ ] موبایل بررسی شده باشد
- [ ] RTL در فرم‌ها، تقویم و منوها سالم باشد
- [ ] `prefers-reduced-motion` کار کند
- [ ] بیلد پروداکشن سالم باشد

## پیوست: آنچه در «تالار مرمر» انتخاب شد

مرجعی برای مقایسه. لازم نیست تکرارش کنید — برای این است که ببینید یک پاسخ کامل چه شکلی است.

| نقش | مقدار | چرا |
|---|---|---|
| زمینه | `#e8eaec` | نقره‌ای سرد، نه سفید خالص |
| سطح | `#fbfcfd` | کارت‌ها روی زمینه |
| متن | `#2e3236` | زغالی گرم — **هرگز مشکی خالص** |
| متن فرعی | `#6b7178` | |
| اکسنت | `#9aa3ac` | نقره‌ای، نه رنگ تند |
| اکسنت عمیق | `#6e777f` | حالت hover |
| طلایی | `#b28c3a` | فقط برای نور و جزئیات نادر |
| خط | `#c7cdd2` | مویی، موتیف اصلی طرح |

**فونت‌ها:** Markazi Text برای تیتر (وزن ۴۰۰–۷۰۰ — بیرون این بازه بی‌اثر است)، Vazirmatn برای متن.

**سه قاعده‌ای که کل حس را ساخت:**
۱. هیچ گوشهٔ گردی در بخش‌های عمومی. خط مویی به‌جای سایه.
۲. تمام ترنزیشن‌های تعاملی ۳۰۰ms روی `cubic-bezier(0.22, 0.61, 0.36, 1)`.
۳. انیمیشن‌های اسکرول **کند** (۶۰۰ms تا ۲ ثانیه) و فقط یک بار. کندی همان چیزی است که لوکس نشان می‌دهد.
