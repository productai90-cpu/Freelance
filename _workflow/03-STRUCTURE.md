## پیوست: بخش‌های آمادهٔ این قالب

هرکدام کار می‌کنند و تست شده‌اند. برای سایت جدید فقط بگویید کدام‌ها بمانند و به چه ترتیبی.

| بخش | فایل | چه می‌کند |
|---|---|---|
| هیرو | `Hero.jsx` | عکس تمام‌صفحه، نام برند، دو دکمه. نورپردازی اختیاری |
| دربارهٔ ما | `About.jsx` | متن + دو عکس روی هم + چهار عدد شمارنده |
| گالری | `Gallery.jsx` | یک عکس بزرگ + دو عکس نامساوی، با لایت‌باکس |
| منو/خدمات | `Menu.jsx` | سه کارت پکیج، هرکدام لایت‌باکس + خروجی PDF |
| نوار تصویری | `CelebrationStrip.jsx` | یک عکس تمام‌عرض با یک جمله. نفس‌کشیدن بین دو بخش سنگین |
| خدمات | `Services.jsx` | شبکهٔ ۴ ستونی با آیکن‌های کشیده‌شونده |
| نظرات | `Testimonials.jsx` | اسلایدر کارت با عکس و امتیاز |
| فرم | `Inquiry.jsx` | فرم استعلام با تاریخ شمسی |
| فوتر | `Footer.jsx` | اطلاعات تماس، بدون لینک پنل |

**پنل مدیریت** (`src/admin/`) جداست و همیشه همراه می‌آید: تقویم، صندوق استعلام، لیست رزروها، صفحهٔ جزئیات. موبایل‌فرست، با ورود.

### قاعده‌های ساختاری که نباید شکسته شوند

- سایت عمومی هرگز از `src/admin/` چیزی import نمی‌کند
- هیچ قیمتی در باندل عمومی نیست
- هیچ لینکی از سایت عمومی به پنل نیست — فقط با آدرس مستقیم
- تاریخ‌ها همیشه شمسی، به شکل متن `۱۴۰۵-۰۶-۱۲`
