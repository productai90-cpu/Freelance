# ۶. ساخت سایت با Claude Code

## قبل از شروع، این‌ها باید آماده باشند

- [ ] `01-BRIEF.md` پر شده
- [ ] `02-DESIGN.md` پر شده
- [ ] `03-STRUCTURE.md` پر شده
- [ ] `04-CONTENT.md` از مشتری برگشته
- [ ] عکس‌ها رسیده و در پوشه‌ای بیرون از مخزن هستند

اگر متن یا عکس نرسیده، **شروع نکنید.** ساختن با متن حدسی یعنی دو بار ساختن.

## کپی گرفتن از قالب

```bash
git clone https://github.com/productai90-cpu/Freelance.git نام-مشتری
cd نام-مشتری
rm -rf .git
git init
npm install
```

## پرامپت — این را در Claude Code بچسبانید

```
این مخزن قالب «تالار مرمر» است. می‌خواهم برای یک مشتری جدید بازسازی‌اش کنی.

فایل‌های زیر را در پوشهٔ _workflow بخوان — پر شده‌اند:
  01-BRIEF.md      اطلاعات کسب‌وکار
  02-DESIGN.md     رنگ، فونت، حس بصری
  03-STRUCTURE.md  بخش‌ها و ترتیبشان
  04-CONTENT.md    همهٔ متن‌ها
  05-ASSETS.md     عکس‌ها (خام‌ها در پوشهٔ «...» هستند)

کارهایی که باید انجام دهی:

۱. src/config.js را با مشخصات کسب‌وکار جدید بازنویسی کن.

۲. توکن‌های رنگ و فونت را در src/styles/index.css طبق 02-DESIGN.md عوض کن.
   فقط توکن‌ها — هیچ کلاس رنگی هاردکد نکن. باید بشود کل تم را از همان
   چند متغیر عوض کرد.

۳. src/data/content.js را با متن‌های 04-CONTENT.md پر کن.
   هیچ متن نمونهٔ فارسی از پروژهٔ قبل باقی نماند.

۴. عکس‌های خام را به .webp تبدیل کن (عرض حداکثر ۱۹۲۰، کیفیت ~۸۲)،
   در src/assets/images/ بگذار و src/data/images.js را به‌روز کن.
   عکس‌های خام نباید وارد گیت شوند.

۵. اگر 03-STRUCTURE.md بخشی را حذف یا اضافه کرده، بخش‌های
   src/public-site/sections/ و ترتیبشان در PublicSite.jsx را تنظیم کن.

۶. جستجو کن و مطمئن شو هیچ اثری از «مرمر» یا مشتری قبلی نمانده —
   در متن، در alt عکس‌ها، در کامنت‌ها، در عنوان صفحه و متا تگ‌ها.

۷. npm run build بگیر و مطمئن شو خطا ندارد.

قاعده‌هایی که نباید بشکنی:
  · سایت عمومی هرگز از src/admin/ چیزی import نکند
  · هیچ قیمتی در باندل عمومی نباشد
  · هیچ لینکی از سایت عمومی به پنل مدیریت نباشد
  · تاریخ‌ها شمسی و به شکل متن «۱۴۰۵-۰۶-۱۲»
  · تمام ترنزیشن‌های تعاملی ۳۰۰ms
  · انیمیشن‌های اسکرول را دست نزن — کندی‌شان عمدی است

اگر جایی از فایل‌ها مبهم یا ناقص بود، قبل از حدس‌زدن از من بپرس.
```
