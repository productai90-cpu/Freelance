## قانون طلایی

**هیچ‌وقت از صفر شروع نکنید.** این مخزن را کپی کنید و روی کپی کار کنید:

```bash
git clone https://github.com/productai90-cpu/Freelance.git نام-مشتری
cd نام-مشتری
rm -rf .git
git init
npm install
```

> این دستورها کجا زده می‌شوند و هر کدام چه می‌کنند: `00-اجرای-دستورها.md`.
> `rm -rf .git` را رد نکنید — بدون آن اولین push تغییرات مشتری جدید را
> داخل مخزن Freelance شما می‌ریزد.

سایت مرمر کامل، تست‌شده و مستندشده است. هر سایت جدید همان است با محتوا و رنگ متفاوت. اگر از نو بنویسید همهٔ باگ‌هایی را که یک بار حل کرده‌ایم دوباره پیدا می‌کنید.

## چه چیزی معمولاً عوض می‌شود، چه چیزی نه

| عوض می‌شود | ثابت می‌ماند |
|---|---|
| رنگ‌ها و فونت‌ها (`src/styles/index.css`) | معماری بخش‌ها |
| متن‌ها (`src/data/content.js`) | سیستم انیمیشن اسکرول |
| مشخصات کسب‌وکار (`src/config.js`) | ساختار پنل مدیریت |
| عکس‌ها (`src/assets/images/`) | دیتابیس و امنیت |
| ترتیب و تعداد بخش‌ها | دیپلوی |

سه فایل اول ۹۰٪ کار یک سایت جدیدند. اگر مشتری همان ساختار را بخواهد، **در یک روز تحویل می‌رود**.
